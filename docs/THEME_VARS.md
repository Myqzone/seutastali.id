# Design Tokens & Theme Variables

## 1. Core Color Palette
| Name | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Maroon** | `#800000` | Bold & Romantic (Primary) |
| **Purple** | `#4B0082` | Elegant & Regal |
| **Yellow** | `#FFD700` | Bright & Joyful |
| **Green** | `#2E8B57` | Natural & Calm (Sage/Forest) |
| **Gold** | `#C5A059` | Accent / Seutas Gold |
| **Dark** | `#121212` | Text & UI Surface |

## 2. Typography Settings
- **Header:** `Srbija Sans`, sans-serif (Font-weight: 700).
- **Body:** `Satoshi`, sans-serif (Font-weight: 400, 500).
- **Letter Spacing:** Headers should have `tracking-tight`.

## 3. Shape & Spacing
- **Radius:** `rounded-2xl` (1rem / 16px) untuk semua container utama.
- **Shadow:** `shadow-xl` dengan opacity rendah untuk kesan "floating".
- **Transition:** `0.4s ease-in-out` untuk semua hover & modal entrance.
