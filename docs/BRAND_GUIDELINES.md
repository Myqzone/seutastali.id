# SeutasTali Brand Blueprint & SEO

## 1. Brand Identity
- **Nama Brand:** SeutasTali (di bawah naungan Sensedegrees).
- **Tagline:** "Satu tautan, beribu cerita."
- **Filosofi Nama:** 
  - **Tautan (Link):** Terjemahan puitis dari URL digital.
  - **Simpul (Bond):** Melambangkan ikatan dan silaturahmi tamu.
  - **Garis Waktu (Timeline):** Merepresentasikan alur cerita klien yang presisi.
- **Profil Sosmed:** "Premium Digital Invitation. Merajut momen dan menyatukan jarak dalam satu tautan estetik. Dirancang oleh @sensedegrees."

## 2. SEO Strategy (Keywords)
AI wajib menggunakan keyword ini dalam komponen `<head>`, meta tags, dan atribut `alt` pada gambar:
- **Primary:** Undangan digital premium, web invitation estetik.
- **Secondary:** Jasa desain undangan custom, undangan website korporat, website pernikahan eksklusif.

## 3. Domain Strategy
- **Primary Domain:** `seutastali.id` (Digunakan untuk operasional & link klien).
- **Protection Domain:** `seutastali.com` (Redirect otomatis ke .id). AI tidak perlu memproses domain .com dalam logic aplikasi.

## 4. Copywriting Tone
- **Voice:** Elegan, Puitis, Profesional, namun Ramah (Friendly).
- **Language:** Bahasa Indonesia yang santun dan estetik (hindari bahasa gaul yang terlalu kasual untuk undangan pernikahan).

# Visual Identity: The Rounded System


## UI Dashboard (Admin)
- Gunakan warna Maroon sebagai warna aksen tombol utama.
- Semua card di dashboard harus `rounded-2xl` agar senada dengan undangan.

## Theme Logic
- Setiap tema harus memiliki 4 varian warna wajib: **Maroon, Purple, Yellow, Green**.
- Font default tetap **Srbija Sans** untuk header agar kesan premium terjaga.
